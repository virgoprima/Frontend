# Опрос Pet ID: как подключить Google Таблицу

Страница опроса (`pet-id/survey/index.html`) отправляет ответы в Google Таблицу через Google Apps Script. Каждый ответ появляется на листе «Ответы» отдельной строкой с датой и временем по Москве.

## 1. Создать таблицу и добавить скрипт

1. Создайте новую Google Таблицу (или откройте существующую), например «Pet ID — ответы опроса».
2. В меню выберите **Расширения → Apps Script**.
3. Удалите всё в открывшемся файле `Code.gs` и вставьте содержимое файла `apps-script/Code.gs` из этой папки.
4. Нажмите **Сохранить** (значок дискеты).

## 2. Опубликовать как веб-приложение

1. Справа вверху нажмите **Начать развертывание → Новое развертывание**.
2. Нажмите на шестерёнку рядом с «Выберите тип» и выберите **Веб-приложение**.
3. Заполните:
   - Описание: `Pet ID survey`
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
4. Нажмите **Начать развертывание**. Google попросит разрешение на доступ к таблице: выберите свой аккаунт → «Дополнительные настройки» → «Перейти на страницу…» → **Разрешить**. Предупреждение о непроверенном приложении появляется, потому что скрипт ваш собственный. Это нормально.
5. Скопируйте **URL веб-приложения**. Он выглядит так: `https://script.google.com/macros/s/…/exec`.

Проверка: откройте этот URL в браузере. Должно появиться `{"ok":true,"message":"Pet ID survey endpoint is running"}`.

## 3. Вставить адрес на страницу

В `pet-id/survey/index.html` найдите строку

```js
const ENDPOINT = "";
```

и вставьте скопированный URL между кавычками. Или просто пришлите URL Claude, и он сам внесёт правку.

## Если потом поменяете скрипт

После правок в `Code.gs` выберите **Развертывание → Управление развертываниями → ✏️ → Версия: Новая версия → Развернуть**. Тогда адрес останется прежним. Если создать *новое* развертывание, адрес поменяется.
